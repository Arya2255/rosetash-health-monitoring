🔌 اتصالات پیشنهادی (Final Wiring)

⚡ تغذیه (Power)

آداپتور YS-502 (+) قرمز──►SUN (J1-4) = VDD5V IN
آداپتور YS-502 (-) آبی/مشکی──►GND (J1-14 / J2-1 / J2-6 / J2-7 / J2-13)
ESP32 3V3 (J1-1)──►W5500 3.3V + DHT22 VDD (پین ۱)
لپ‌تاپ USB──►micro-USB ESP32 (فقط برنامه‌ریزی)
W5500 پین 5V──►خالی بگذار (NC)
ESP32 5V (J1-19)──►خالی بگذار (NC در Schematic)

🌐 W5500 Ethernet (HSPI سخت‌افزاری)

W5500 SCLK──►P14 / GPIO14 (J1-12)
W5500 MISO──►P12 / GPIO12 (J1-13)
W5500 MOSI──►P13 / GPIO13 (J1-15)
W5500 CS (SCSn)──►P16 / GPIO21 (J2-12) یا GPIO5 اگر آزاد باشد
W5500 RSTn──►P25 / GPIO25 (J1-9) Active Low، ≥500µs
W5500 INTn──►P18 / GPIO34 (J2-9) اختیاری، فقط ورودی
W5500 3.3V──►3V3 (J1-1)
W5500 GND──►GND مشترک

🌡️ DHT22 / AM2302 (Single-Bus)

DHT22 VDD (پین ۱، قرمز)──►3V3 (J1-1)
DHT22 DATA (پین ۲، زرد)──►P23 / GPIO23 (J2-2) + Pull-up 5kΩ به 3V3
DHT22 NC (پین ۳)──►معلق (Floating) — وصل نکن!
DHT22 GND (پین ۴، مشکی)──►GND مشترک
فاصله نمونه‌برداری──►≥ ۲ ثانیه (اجباری)

⚠️ تضادها و نکات حیاتی

GPIO23 (P23/TX/P5)──►DHT22 DATA + W5500 CS Konflit! → یکی عوض کن
GPIO22 (P22/RX/P17)──►UART0 RX/TX — اگر Serial استفاده می‌کن، رزرو کن
GPIO4──►روی هدر نیست! (J2-13 P4 = GND)
فلش داخلی (GPIO6-11)──►SD2,SD3,SD1,SD0,CLK,J1-18 — استفاده نکن
فقط ورودی (34,35,36,39)──►SUP, P35, P18 — خروجی نده

📋 نکات مهم اجرا

  • ✓ آداپتور YS-502 + USB همزمان امن است — دیود شاتکی 1N5819 (D1) روی برد ESP32 از برگشت جریان به USB جلوگیری می‌کند (Schematic تأیید شده).
  • ✓ W5500 تغذیه ۳.۳V مستقیم از ESP32 بگیر — ماژول رگولاتور AMS1117 روی برد دارد اما ۳.۳V مستقیم نویز کمتر دارد. پین ۵V ماژول را خالی بگذار.
  • ✗ GPIO4 روی هدر شما وجود ندارد — J2-13 برچسب P4 دارد اما Schematic و برد واقعی هر دو GND هستند. برای W5500 RST از GPIO25 (J1-9) یا GPIO21 (J2-12) استفاده کنید.
  • ✗ پین J1-19 برچسب 5V دارد اما NC است — به هیچ‌چیز وصل نکنید.
  • ✗ پین J1-17 (SD3) برچسب GND دارد اما Schematic می‌گوید GPIO11 (CMD/فلش داخلی) — در برد واقعی زمین است، برای GPIO استفاده نکنید.
  • ⚠ DHT22 DATA و W5500 CS هر دو می‌خواهند GPIO23 — پیشنهاد: W5500 CS = GPIO21 (J2-12 P16)، DHT22 DATA = GPIO23 (J2-2 P23).
  • ⚠ Pull-up ۵kΩ برای DHT22 DATA الزامی است — بین پین DATA (GPIO23) و 3V3 وصل کنید.
  • ✓ پورت سریال: CP2102 — در لینوکس معمولاً /dev/ttyUSB0، درایور پیش‌فرض دارد.
  • ✓ ماژول ESP32: ZY-ESP32 (FC/CE/SRRC) — معادل ESP32-WROOM-32، cristal 40MHz داخلی دارد.
  • ✓ RJ45: HanRun HR911105A — مگنتیک یکپارچه، نیاز به ترنسفورمر خارجی ندارد.
