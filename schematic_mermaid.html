📋 نکات حیاتی اجرا

  • ✓ آداپتور YS-502 + USB همزمان امن — دیود شاتکی 1N5819 (D1) روی برد ESP32 از برگشت جریان جلوگیری می‌کند.
  • ✓ W5500 تغذیه ۳.۳V مستقیم از ESP32 3V3 — پین ۵V ماژول OPTIONAL (خالی بگذار). ماژول HanRun HR911105A شامل مگنتیک یکپارچه.
  • ✗ GPIO4 روی هدر وجود ندارد — J2-13 (P4) = GND. برای W5500 RST از GPIO25 (J1-9) یا GPIO21 (J2-12) استفاده کنید.
  • ✗ J1-19 برچسب 5V دارد اما NC است — به هیچ‌چیز وصل نکنید.
  • ✗ فلش داخلی GPIO6-11 روی هدر موجودند — SD2,SD3,SD1,SD0,CLK = GPIO9,10,27,26,25 ❌ استفاده نکنید.
  • ⚠ تضاد GPIO23 — DHT22 DATA و W5500 CS هر دو می‌خواهند GPIO23. حل: W5500 CS → GPIO21 (J2-12 P16), DHT22 DATA → GPIO23 (J2-2 P23).
  • ⚠ Pull-up ۵kΩ برای DHT22 DATA الزامی — بین GPIO23 و 3V3.
  • ⚠ فقط‌ورودی: GPIO34,35,36,39 — SUP(J1-3), P35(J1-6), P18(J2-9) — خروجی ندهید.
  • ✓ پورت سریال CP2102 — در لینوکس /dev/ttyUSB0، درایور پیش‌فرض.
  • ✓ ESP32 Module: ZY-ESP32 (WROOM-32 equivalent) — FCC/CE/SRRC، Cristal 40MHz داخلی.
