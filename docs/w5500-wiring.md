# سیم‌کشی W5500 به ESP32

## پایه‌های مورد نیاز (HSPI)

ما از باس SPI دوم ESP32 (HSPI) استفاده می‌کنیم:

| پایه ESP32 | پایه W5500 | توضیح |
|------------|------------|-------|
| GPIO 14 | SCK | ساعت SPI |
| GPIO 12 | MISO | داده از W5500 به ESP32 |
| GPIO 13 | MOSI | داده از ESP32 به W5500 |
| GPIO 5 | CS (SCN) | انتخاب تراشه |
| 3.3V | VCC | تغذیه |
| GND | GND | زمین |
| (اختیاری) GPIO 4 | RST | ریست |

> ⚠️ **توجه:** W5500 با ۳.۳ ولت کار می‌کند — نیاز به سطح‌سنج سطح ندارد.

## تصویر سیم‌کشی

```
                    W5500 Module
                   ┌────────────┐
           3.3V ──┤ VCC   RST  ├── (اختیاری به GPIO 4)
            GND ──┤ GND   INT  ├── (بدون اتصال)
       GPIO 13 ──┤ MOSI  CS  ├── GPIO 5
       GPIO 12 ──┤ MISO  SCK ├── GPIO 14
                   └────────────┘

                    ESP32 DevKit
                   ┌────────────┐
           3.3V ──┤ 3V3       VIN ├── 5V (خارجی)
            GND ──┤ GND       GND ├── GND
        GPIO 14 ──┤ D14       D23 ├──
        GPIO 12 ──┤ D12       D22 ├──
        GPIO 13 ──┤ D13       TX0 ├──
         GPIO 5 ──┤ D5        RX0 ├──
         GPIO 4 ──┤ D4        D21 ├── (اختیاری: RTS)
                   └────────────┘
```

## نکات مهم

1. **ترتیب پایه‌ها در ماژول W5500:**
   - اکثر ماژول‌ها ترتیب استاندارد دارند: VCC, GND, MOSI, MISO, SCK, CS
   - حتما دیتاشیت ماژول خود را چک کنید

2. **منبع تغذیه:**
   - W5500 حداقل ۱۵۰ میلی‌آمپر نیاز دارد
   - از خروجی ۳.۳ ولت ESP32 استفاده کنید (حداکثر ۵۰۰ میلی‌آمپر)

3. **کابل اترنت:**
   - کابل را به پورت RJ45 وصل کنید
   - لینک باید روشن شود (LED روی ماژول)

## کد تست

### تست اولیه (بدون کتابخانه)

```arduino
// فایل: firmware/gateway/w5500_direct/w5500_direct.ino
SPI.begin(14, 12, 13, 5);  // SCK, MISO, MOSI, CS
```

### تست با کتابخانه Ethernet2

```arduino
// فایل: firmware/gateway/w5500_test_eth2/w5500_test_eth2.ino
#define W5500_CS 4
Ethernet.init(W5500_CS);
```
