# تحقیق بازار: ترکیب مچ‌بند + گیت‌وی برای پایش سلامت کارکنان

- تاریخ: ۲۰۲۶-۱۰-۱۱
- منبع: ایجنت تحقیق هرمس — گزارش با منابع
- توصیهٔ کلی: بند OEM سلامت دارای SDK و لرزش (Veepoo/JCVital) + گیت‌وی اتصال‌محور (لینوکسی یا همان ESP32) با MQTT به سرور محلی.

## جمع‌بندی

تحقیق بازار (اکتبر ۲۰۲۶) نشان می‌دهد ترکیب «یک فروشنده، بند سلامت + گیت‌وی صنعتی با API محلی + لرزش» در بازار عملاً وجود ندارد و بازار به سه گروه می‌شکند:

۱. سازندگان چینی گیت‌وی/تگ BLE (Minew, MOKO, Dusun) با API باز و ارسال به سرور خودتان — ولی بندهایشان ضربان قلب ندارند؛
۲. اکوسیستم‌های سلامت (Cassia, Polar, SlateSafety) با HR/SpO2 واقعی — ولی گران، عمدتاً آمریکایی/اروپایی و برای ایران غیرقابل‌خرید؛
۳. بندهای OEM سلامت چینی (Veepoo, JCVital) با SDK و لرزش که به یکپارچه‌سازی سفارشی نیاز دارند.

کانال خرید ایران: AliExpress به ایران ارسال نمی‌کند (ziranzi.com/aliexpress-countries-0g، irdelivery.com/en/buying-from-ali-express)؛ عملاً Alibaba/تأمین مستقیم چین با واسطه یا فورواردر.

نکتهٔ فنی کلیدی: گیت‌وی‌های اسکن‌کنندهٔ تبلیغ BLE (Minew/MOKO) ضربان بندهای شخص‌ثالث که اتصال GATT می‌خواهند را نمی‌خوانند؛ برای HR باید گیت‌وی اتصال‌محور (Cassia، Dusun لینوکسی، یا همان ESP32) داشت.

## کاندیدها

**Minew (چین)** — گیت‌وی: G1 (MQTT/HTTP/TCP، برد ~۳۰۰m، ۴۰۰ بسته/ث) و خط جدید MG: MG4 (۳۹$؛ PoE + باتری پشتیبان ۱۲ساعته، MQTT/HTTP، ~۱۸۰m، ۳۵۰ بسته/ث، دمای کاری −۲۰..۵۵°C)، MG11/MG7 (۲۵$)، MG3 (۱۹$) — minew.com/product/g1-iot-bluetooth-gateway، minewstore.com. بند: B10 (۱۵$؛ موتور لرزش، SOS، IP66، باتری تا ۶۰ روز) و B8 Plus (لرزش + دمای بدن، SDK) — بدون HR. ایران: قابل تأمین از چین (استعلام). Fit: گیت‌وی «خوب»، بند «متوسط».

**MOKO (چین)** — گیت‌وی MK107/MKGW (MQTT v3.1.1 + JSON به سرور خودتان؛ MK107Pro تا ۴۰۰m با Coded PHY؛ ۳۱۷ بسته/ث؛ MKGW1-BW Pro تا ۳۰۰ دستگاه/ث) — docs.mokosmart.com، store.mokosmart.com. بند W6/W3 Pro فقط بیکن/SOS/تشخیص حرکت؛ بدون HR. قیمت: نامشخص. Fit: متوسط.

**Cassia (آمریکا)** — E1000/X1000/M2000 و ATX2000 (ضدانفجار). گیت‌وی اتصال‌محور (X1000 تا ۲۲ دستگاه؛ ATX2000 تا ۴۰ دستگاه، PoE/۲۲۰V)، نرم‌افزار IoT AC با نصب روی سرور داخلی (non-hosted) + REST API/SDK. مطالعهٔ موردی رسمی: پایش سلامت کارگران پتروشیمی با HR/فشار/SpO2 و «یادآور لرزشی» — cassianetworks.com/case-study. قیمت کیت (غیرهاست‌شده، شامل لایسنس ۱سالهٔ AC): E1000 ۳۸۴.۳۵$، M2000 ۲۰۷.۹۴$، X2000 ۶۹۸.۶۱$ (cassianetworks.com/products/enterprise-starter-kits). ایران: عملاً غیرقابل‌خرید. Fit: فنی خوب، عملیاتی ضعیف.

**Polar (فنلاند)** — Verity Sense: ۱۰۴.۹۵$ (€۹۹.۹۰)؛ سنسور استاندارد BLE HR (تا ۳۰ ساعت، برد انتشار تا ۱۵۰m، دو اتصال همزمان)؛ بدون لرزش. Team Pro سیستمی/ابری (~€۱۷٬۲۱۶ سیستم کامل، footyapps.com). ایران: غیرقابل‌خرید. Fit: ضعیف (لرزش ندارد).

**SlateSafety (آمریکا)** — BAND V2: HR + تخمین دمای مرکزی + تلاش + تشخیص سقوط + GPS + هشدار لمسی TapAlert؛ پورتال ابری اجباری؛ برآورد ~۲٬۰۰۰–۶٬۷۰۰$ سال اول برای ۱۰ نفر (iot-apps.com). ایران: غیرقابل‌خرید. Fit: فنی خوب، عملیاتی ضعیف.

**SmartCap / Fatigue Science ReadiWatch** — پایش خستگی صنعتی، ابری، قیمت نامشخص. Fit: ضعیف (فقط خستگی، بدون HR پیوسته).

**بندهای OEM سلامت چینی** — Veepoo (SDK با «HR/IMU realtime + کنترل موتور لرزش»، github.com/HBandSDK) و JCVital V4 از Shenzhen Youhong (alibaba listing با SDK/API)؛ HR/SpO2/HRV + لرزش؛ قیمت نامشخص. نیاز به پل گیت‌وی سفارشی: Dusun DSGW (OpenWrt/Linux، MQTT/HTTP، Ble2Mqtt) یا حفظ ESP32 فعلی. Fit: «خوب، نیازمند توسعه».

**مسیر باز/استاندارد** — PineTime با فریمور InfiniTime: ۲۶.۹۹$؛ سرویس استاندارد ضربان 0x180D + ANS برای لرزش (doc/ble.md)، باتری ~۱ هفته (pine64.org)، گارانتی ۳۰ روز؛ Bangle.js 2 از £۸۳ (espruino.com/Bangle.js2). بندهای استاندارد بدون لرزش: CooSpo H808S (۳۵.۰۹$). «فقط تعویض بند» با ESP32 فعلی: ممکن (GATT) ولی بدون لرزش، مگر PineTime/بند OEM.

**غیر-BLE (کوتاه)** — LoRaWAN: ساعت‌های ED20W (HR+SOS، باتری ۷ روز @۱۵دقیقه) و GlobalSat LW-360HR (HR+دمای پوست، ۱–۱۰km) — برد عالی ولی HR دوره‌ای و لرزش مستندنشده؛ گیت‌وی LoRaWAN محلی در ایران موجود است (itmc.ir، giot.ir). Zigbee: اکوسیستم HR ندارد.

## مقایسه

- HR: Cassia/SlateSafety/Polar/OEM/PineTime ✓ | Minew/MOKO ✗
- لرزش: Minew B10/B8، OEM، PineTime، SlateSafety ✓ | Polar ✗
- API محلی/سرور خودی: Minew، MOKO، Cassia (non-hosted)، Dusun ✓ | SlateSafety/Polar ابری
- برد: MOKO ~۴۰۰m، Minew ۱۸۰–۳۰۰m، Cassia ~۳۰۰m، LoRaWAN کیلومترها
- هزینه/کارگر: Minew ~۵۴$ (بدون HR)؛ PineTime+MG4 ~۶۶$ (HR+لرزش، DIY)؛ Cassia از ~۲۰۸$+لایسنس سالانه؛ SlateSafety ~۲۰۰–۶۷۰$/نفر سال اول
- ایران: چینی‌ها/OEM با واسطه؛ Cassia/Polar/SlateSafety ✗

## پیشنهاد نهایی

۱) **مسیر اصلی (توصیه):** بند OEM سلامت با SDK و لرزش (Veepoo/JCVital) + گیت‌وی لینوکسی با MQTT به سرور محلی (Dusun یا ارتقای ESP32 موجود). HR/SpO2/لرزش + بدون ابر + قابل تأمین از چین؛ نیازمند پایلوت و کار یکپارچه‌سازی. اگر توسعه نمی‌خواهید: PineTime (HR استاندارد + لرزش، ۲۷$) با همان گیت‌وی GATT.

۲) **زیرساخت و لایهٔ هشدار (بدون HR):** Minew MG4 (۳۹$، PoE، MQTT/HTTP) + B10 (۱۵$، لرزش/SOS/۶۰ روز باتری) — حل مستقیم برد، تغذیه و نگهداری.

۳) **بنچمارک فنی (نه خرید ایران):** Cassia + بند سازگار؛ تنها اکوسیستمی که پایش سلامت کارگر با لرزش را مستند اجرا کرده است.

## سؤال‌ها و نقاط نامشخص

- قیمت‌های نامشخص: MOKO، Dusun، Veepoo/JCVital، SmartCap، ReadiWatch، Cassia X1000/ATX2000 تک‌واحدی، هزینهٔ ارسال PineTime به ایران.
- آیا بندهای OEM ضربان را در ADV منتشر می‌کنند یا فقط GATT؟ (سازگاری با گیت‌وی اسکن‌کننده).
- عمر واقعی باتری بند OEM با HR پیوسته و دوام شیفت کاری.
- شرایط واقعی پرداخت/ارسال/گمرک به ایران برای هر تأمین‌کننده.
- پشتیبانی بلندمدت SDK (اجرای SDK وپیو روی گیت‌وی لینوکسی پورت‌نشده است).
- الزامات گواهی برای محیط صنعتی (آیا CE/FCC کافی است یا ATEX لازم است).
