================================================================================
نقشه سیم‌کشی ESP32 DevKit V1 (30-pin) + W5500 + DHT22
================================================================================

۱. اتصال W5500 به ESP32
─────────────────────────────────────────────────
W5500 پایه     →    ESP32 پایه    →    رنگ پیشنهادی
─────────────────────────────────────────────────
VCC            →    3.3V          →    قرمز
GND            →    GND          →    سیاه
SCK            →    GPIO18 (D18)  →    نارنجی
MISO           →    GPIO19 (D19)  →    زرد
MOSI           →    GPIO23 (D23)  →    سبز
CS/SCS         →    GPIO5 (D5)    →    آبی
RST            →    GPIO4 (D4)    →    بنفش
INT            →    GPIO21 (D21)  →    سفید

۲. اتصال DHT22 به ESP32
─────────────────────────────────────────────────
DHT22 پایه     →    ESP32 پایه    →    رنگ پیشنهادی
─────────────────────────────────────────────────
VCC            →    3.3V          →    قرمز
GND            →    GND          →    سیاه
DATA           →    GPIO2 (D2)    →    نارنجی
NC             →    بدون اتصال     →    -

۳. اتصال منبع تغذیه
─────────────────────────────────────────────────
منبع تغذیه     →    ESP32 پایه    →    رنگ پیشنهادی
─────────────────────────────────────────────────
5V (مثبت)      →    VIN یا 5V     →    قرمز
GND (منفی)     →    GND          →    سیاه

================================================================================
نکات مهم ⚠️
================================================================================

۱. ⚡ قبل از روشن کردن:
   • همه GNDها رو مشترک کن
   • VCC رو به 3.3V وصل کن (نه 5V!)
   • سیم‌های SPI رو کوتاه بکش (< 10cm)

۲. 🔌 تغذیه:
   • ESP32 می‌تونه از USB تغذیه بشه (نیازی به منبع خارجی نیست)
   • اگه منبع خارجی استفاده می‌کنی → VIN/5V پایه

۳. 📋 پایه‌های مهم ESP32:
   • GPIO0 = دکمه Boot/Flash
   • GPIO2 = LED داخلی + DHT22 DATA
   • EN = دکمه Reset

۴. ⚠️ GPIO4:
   • به RST وصل میشه (نه به منبع تغذیه!)
   • برای ریست کردن W5500
