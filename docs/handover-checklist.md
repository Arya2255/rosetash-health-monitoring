# چک‌لیست روز تحویل — نمایش سیستم پایش

راهنمای کوتاه برای وقتی می‌خواهی سیستم را به کارفرما یا تیم نشان بدهی.

## راه سریع

    bash scripts/start_demo.sh --check     # فقط بررسی وضعیت اجزا
    bash scripts/start_demo.sh             # بروکر + پل + برنامهٔ دسکتاپ
    bash scripts/start_demo.sh --web       # نسخهٔ وب روی پورت ۸۵۵۰

## ترتیب روشن کردن به‌صورت دستی

۱. بروکر تست محلی:

    cd ~/Projects/rosetash-health-monitoring
    mosquitto -c tools/mosquitto/mosquitto.conf

۲. پل زنده در یک ترمینال جدا:

    python3 backend/bridge.py

۳. کنترل سلامت پل:

    curl 127.0.0.1:8726/health

۴. برنامه:

    uv run flet run

## نمایش پایش زنده

- مچ‌بند را روی دست بگذار و نزدیک گیت‌وی بایست تا در صفحهٔ «پایش زنده» دیده شود.
- چیپ سبز «دریافت زنده از پل محلی» یعنی زنجیرهٔ واقعی کار می‌کند.
- کارت‌ها: قدرت سیگنال مچ‌بند، آخرین ضربان، وضعیت گیت‌وی و پنجرهٔ سلامت.
- ردیف دوم کارت‌ها: باتری، اکسیژن خون، HRV و قدم. باتری هر پنجره خوانده می‌شود؛
  اکسیژن و HRV هر پنج پنجره (حدود ۵ دقیقه) یک‌بار اندازه‌گیری می‌شوند — تا رسیدن قرائت صبر کن.
- برای نمایشگر کنار خط: `ROZTASH_VIEW=live uv run flet run` — برنامه مستقیم روی پایش زنده باز می‌شود.
- در داشبورد هم نوار بالای صفحه دادهٔ زندهٔ گیت‌وی را نشان می‌دهد.

## اگر مچ‌بند در دید نبود — دموی بازپخش

    python3 tools/replay_events.py --demo --speed 4

اپیزود واقع‌نما را روی بروکر می‌فرستد؛ چند ثانیه بعد صفحهٔ زنده پر می‌شود. این حالت برای نمایش بدون سخت‌افزار است.

## صداقت در ارائه — چه چیزی واقعی است

- دادهٔ زنده: صفحهٔ «پایش زنده» و نوار زندهٔ داشبورد — از گیت‌وی واقعی.
- نمایشی: کارت‌ها و فهرست کارکنان در بقیهٔ صفحه‌ها با ۲۴ کارکن نمونه ساخته شده‌اند.
- این تفاوت را در ارائه شفاف بگو؛ اعتبار دمو به همین شفافیت است.

## پرسش‌های احتمالی و پاسخ کوتاه

- «چند گیت‌وی لازم است؟» — با محاسبهٔ ظرفیت، سه تا چهار گیت‌وی؛ تعداد نهایی بعد از تست پوشش میدانی.
- «برد چقدر است؟» — اسکن تا حدود ۳۰ متر، برد مطمئن اتصال داخل سالن پرمانع حدود ۸ تا ۱۵ متر.
- «اگر وای‌فای قطع شود؟» — داده در حافظهٔ گیت‌وی صف می‌شود و بعد از وصل شدن ارسال می‌شود.
- «حریم خصوصی؟» — گیت‌وی فقط شناسهٔ مچ‌بند را می‌فرستد؛ نقشهٔ شناسه به کارکن فقط در سیستم HSE است.

## قدم‌های بعد از تحویل

۱. دیدبند کارخانه: تعداد کارکنان و نقاط نصب نهایی
۲. تست پوشش میدانی و تثبیت چیدمان گیت‌وی
۳. انتقال پل به سیستم دائمی اتاق HSE و بکاپ
۴. قواعد هشدار و آژیر روی جریان واقعی
